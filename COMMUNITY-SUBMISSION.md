# LoopGrid for Agno — Community Submission

## Integration

LoopGrid Agno Integration

## Description

LoopGrid provides signed, independently verifiable decision evidence for Agno agents and teams.

The integration connects with Agno agent lifecycle hooks to capture:

- agent decisions
- tool execution context
- policy evaluation context
- observed outcomes

Evidence records are cryptographically verifiable using LoopGrid verification workflows.
